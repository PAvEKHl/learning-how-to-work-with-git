# learning-how-to-work-with-git

Учебный монорепозиторий: NestJS (backend) + NextJS (frontend).
Цель — отработать профессиональный Git-workflow в консоли.

## Структура

```
├── backend/   # NestJS API
├── frontend/  # NextJS приложение
└── README.md
```

## Ветки

- `main` — релизная ветка (стабильный код)
- `dev` — ветка разработки (интеграция фич)

Новая работа ведется в отдельных ветках `feature/*` от свежего `origin/dev`.
